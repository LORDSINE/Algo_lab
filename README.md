# COMP-314: Algorithms and Complexity Lab Work

This folder contains the adapted lab implementations for the COMP-314 course (Algorithms and Complexity).
Each lab has its own directory under `mine/lab_X/`, with source code in `src/`, generated results in `results/`, and generated figures in `figures_X/`.

## Directory Structure

- `lab_1/`
  - `src/`
    - `algorithms.py`
    - `run_experiments.py`
    - `plot_results.py`
    - `main.py`
  - `results/`
  - `figures_1/`

- `lab_2/`
  - `src/`
    - `algorithms.py`
    - `run_experiments.py`
    - `plot_results.py`
    - `main.py`
  - `results/`
  - `figures_2/`

- `lab_3/`
  - `src/`
    - `algorithms.py`
    - `run_experiments.py`
    - `plot_results.py`
    - `main.py`
  - `results/`
  - `figures_3/`

## Requirements

- Python 3.8+
- `matplotlib`

Install dependencies with:

```bash
python -m pip install matplotlib
```

## Usage

Each lab can be executed using the wrapper script `main.py` in the lab source folder.
This runs both the experiment generator and the plotting script.

### Lab 1

```bash
python mine/lab_1/src/main.py
```

### Lab 2

```bash
python mine/lab_2/src/main.py
```

### Lab 3

```bash
python mine/lab_3/src/main.py
```

## Output

- `results/` stores CSV data generated by `run_experiments.py`
- `figures_X/` stores plots generated by `plot_results.py`
